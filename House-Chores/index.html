🔒 Firebase Permission Error Your database rules are blocking access (this happens after 30 days in test mode). Fix it in 30 seconds:
  1. Go to console.firebase.google.com
  2. Select project house-chores-5adf7
  3. Click Realtime Database → Rules
  4. Replace the rules with:
    { "rules": { ".read": true, ".write": true } }
  5. Click Publish, then try again
🔒 Firebase write blocked
Your Realtime Database rules are denying writes. Test-mode rules auto-lock after 30 days — that's the most common cause.

    { "rules": { ".read": true, ".write": true } }
  4. Click Publish, then reopen this app
